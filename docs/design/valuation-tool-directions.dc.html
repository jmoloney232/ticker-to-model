How I read the brief
Material. The Industry system you attached — steel #5980a6 on #f2f2f3, Barlow Condensed over Barlow, square hairline frames with registration marks. It already reads as a spec sheet, which suits a model. I added IBM Plex Mono for every figure, since the system carries no tabular face.
Color as data only. Steel marks user-edited values and heat in the sensitivity grid. Two semantic tones beyond the palette: ochre #a8752a for caveats, rust #9e4b3c for a value below market. Nothing is colored for mood, nothing is colored for brand.
All three keep the comparison above the fold. They differ in where it sits and what shape it takes: an axis band (1a), a paired-bar plate in a three-pane rail layout (1b), a price bridge on a reversed steel field (1c). Same data, same tokens, same 25 fields.
1aTape. Two panes. The growth reconciliation is a full-width axis band across the top — you read the gap as distance. The rule behind whichever field is selected prints in a fixed inspector strip at the foot of the assumptions pane, so no row has to carry its own explanation.
