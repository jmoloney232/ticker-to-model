# frontend — React + TypeScript (Vite)

Ticker search → dashboard (value vs price, FCF bridge, sensitivity grids, validation
status) → assumptions panel (default + derivation shown, overrides highlighted) →
workbook download, plus the `/methodology` page rendered from the backend's
`methodology.yaml`. Spec: [`specs/06-webapp.md`](../specs/06-webapp.md). Scaffolded with
Vite in phase 4; deploys as a static site on Vercel (API on Render).
